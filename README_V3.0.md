# V3.0 医患关系与数据基础版

## 本阶段目标
从 V2.9.x 医生工作台继续进入真正的产品化基础层：账号、角色、医患关系、持久化数据库、审计基础。

## 新增
- SQLite 持久化数据库
- doctor / patient 角色
- 医生登录会话
- 医生患者列表 API
- 医患绑定 API
- 登录与绑定审计
- V3.0 基础测试页
- 保留 V2.9.28 医生端三文件

## 测试
在 backend 目录执行：
node v3-server.js

打开：
v3/index.html

演示账号：
doctor001 / demo-doctor

患者：P0001、P0002

## 安全边界
本版本只实现身份、关系、数据基础，不改变现有 RED/YELLOW/REVIEW 风险规则，也不增加诊断或治疗决策。

## 注意
这是 V3.0 第一阶段基础版，不等同于生产上线版本。正式上线前仍需完善密码哈希、正式认证/会话、权限隔离、HTTPS、数据库备份、日志、隐私与合规审查。
